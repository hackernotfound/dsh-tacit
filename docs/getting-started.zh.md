# 快速开始

> 本文由英文版翻译而来，尚未经过母语者校对；以 [getting-started.md](getting-started.md) 为准，欢迎提交修正。

*写给第一次安装 Tacit 的人。大约五分钟。*

## 前置条件

| 你需要 | 说明 |
| --- | --- |
| DeepSeek Harness（`dsh`） | 版本 `>= 0.1.1-rc.1`——用 `npx @deepseek-ai/dsh --version` 查看 |
| Node.js | `>= 22` |
| 一个 DeepSeek API Key | 已在 harness 里配置好（**设置 → 模型**）。Tacit 从不读取它：每次模型调用都经过 harness 自己的模型服务。 |

## 安装

```bash
npx @deepseek-ai/dsh plugin --profile web add dsh-tacit
```

如果 CLI 已经全局安装，也可以用更短的 `dsh plugin --profile web add dsh-tacit`。

然后**启动（或重启）`npx @deepseek-ai/dsh web`**，并**刷新浏览器页面**。Tacit 有两半：
一半运行在 `dsh` 进程里（需要重启），一半运行在浏览器里（需要刷新）。

## 确认它已启用

- 任意对话里都会多出一个 **Tacit** 标签页，在 *Chat / Trajectory / Context* 旁边。
- **设置 → Tacit** 显示 *已从 0 条提示词学习* 和 *自动学习已开启 · 今天 0/30*。

如果没有这个标签页，再重启一次 `npx @deepseek-ai/dsh web`，并检查上面的版本要求。

## 可选：从你已经做过的事里学习（快速起步）

Tacit 会边用边学，但你可以用最近的历史给它一个起点。有两个按钮，文字相同、范围不同：

| 按钮 | 位置 | 看的范围 |
| --- | --- | --- |
| *从我最近 20 轮中学习* | Tacit 标签页 | 仅当前对话 |
| *从我最近 20 轮中学习* | 设置 → Tacit | 当前加载的所有对话 |

它做的事：取最近 20 个已完成的轮次，跳过少于 8 个字符的提示词、纯粹的"继续"类
消息（"continue"、"ok"）以及已经分析过的轮次，逐个分析剩下的，然后做一次蒸馏，
生成第一批指令。它**不受**每日上限限制。费用：按公开价格大约 $0.02–0.05，一次性
（见 [隐私与成本](privacy-and-cost.md#cost)，英文）。

## 然后照常工作

无需再做别的。Tacit 会在后台对两种信号做出反应：

| 信号 | 例子 | 会发生什么 |
| --- | --- | --- |
| 一轮结束得**不顺**——有重试、工具报错、上下文压缩、取消/拒绝，或 15 步以上的模型步骤 | 智能体在回答前翻来覆去调用了很多工具 | 分析该轮的提示词 |
| 你的下一条消息像是**纠正**（很短，以"no"、"wrong"、"I meant"、"不对"……开头） | *"不对，我是说 apps/web 下的 Next.js 应用"* | 分析*上一轮*的提示词，并把你的纠正作为证据 |

每 3 次分析之后，Tacit 会把学到的东西蒸馏成 1–4 条**指令**。新指令先作为*候选*
试用 10 个已完成轮次；如果你的不顺轮次比例没有变差就变为*生效*，否则*退役*。
指令会注入每个**新**对话的系统提示（不包括正在进行的那个）。原文可在
**设置 → Tacit → 实际注入的文本** 查看。

带真实数字的细节见 [How it works](how-it-works.md)（英文）。

## 界面各处在哪

| 界面 | 你会看到 | 能做什么 |
| --- | --- | --- |
| **Tacit 标签页**（对话视图） | 每轮一行：工具调用、步数、token、重试；已分析的轮次带有 *auto / correction / manual / bootstrap* 标记；提示词；*发送前补充的上下文*（仅开启 `enrichPrompts` 时）；分析报告 | 对单轮 *分析* / *重新分析*；*选择提示词…* → *分析所选*；*从我最近 20 轮中学习*（当前对话）；内嵌的设置开关 |
| **设置 → Tacit** | 已学习的数量、自动学习状态（今天 / 上限）、实测趋势（不顺轮次比例和每轮 token，最早 20 轮 vs 最近 20 轮——40 个已完成轮次之后出现） | 快速起步（所有对话）；分析模型（`deepseek-v4-flash` / `deepseek-v4-pro`）；*自动分析混乱轮次*；*每日自动分析上限*；*启用输入框改进按钮*；*清除所有会话的分析报告* |
| **设置 → Tacit → 智能体被告知的关于你的内容** | 每条指令及其状态标签（*试用 3/10*、*生效*、*退役 · 原因*）和来源标签（*你添加的* / *蒸馏得到的*）；*学到的风格规则*；跨对话的*已分析提示词* | 开关 / 删除 / 添加指令；*把学到的指令注入系统提示* 和 *发送前补充学到的上下文* 两个开关；*实际注入的文本* |
| **输入框** | 输入框左侧的 **✨ 改进提示词** 按钮 | 用 Tacit 学到的东西重写当前草稿；前后对比预览 → *应用*；然后出现一条 *这样更好吗？* 👍/👎（👎 会请你写一句原因） |

## 排障

**什么都没被分析。**
自动分析只看*插件启动之后完成*的轮次（重启会重置这一点），只在该轮不顺或你的
下一条消息是纠正时触发，并且从不分析纯粹的"继续"类消息。看看 **设置 → Tacit**：
自动学习是否开着？今天的次数是否还在上限（默认 30）以内？你随时可以在 Tacit
标签页里手动分析某一轮。

**我改了一条指令，智能体还是不理会。**
steering 文本在对话开始时就冻结了（为了让模型的提示缓存保持有效）。开一个新对话。

**趋势标签不见了。**
需要当前加载的对话里至少有 40 个已完成轮次。

**没有 ✨ 按钮。**
它被关掉了：设置 → Tacit → *启用输入框改进按钮*（`liveSuggestions`）。

**手动分析提示"continuation"。**
很短的继续类提示词（"continue"、"go ahead"、"yes"）永远不会被分析——它们的上下文
在上一轮里。没有发生模型调用。

**我的数据在哪？**
`~/.dsh/storages/tacit/`（如果设置了 `DSH_HOME`，则是 `$DSH_HOME/storages/tacit/`）。
见 [隐私与成本](privacy-and-cost.md)（英文）。

**我以前用的是 `dsh-prompt-coach`。**
Tacit 是它的后继者。首次启动时，如果新目录不存在，会把 `storages/prompt-coach`
重命名为 `storages/tacit`。不会删除任何东西。
